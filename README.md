# 🛡️ Text RPG Project

16단계 과정을 통해 구현된 **C++ 기반 텍스트 RPG 게임**입니다. 
객체지향 프로그래밍의 핵심 원칙을 적용한 플레이어 직업군, 몬스터, 전투 시스템 및 인벤토리 기능을 포함하고 있습니다.

<br>

## 📁 폴더 구조 (Project Structure)
프로젝트는 단계별 학습 내용에 따라 두 개의 주요 폴더로 구성되어 있습니다.

- **`/Step1`**: 프로젝트의 기초를 다지는 단계 (Step 1 ~ 3 구현)
- **`/Project1`**: 본격적인 OOP 적용 및 완성 단계 (필수 Step 4 ~ 8 + 도전 1 ~ 8 구현)

## 💡 주요 구현 기능 (Key Features)

### 1. 다형성을 활용한 직업 시스템 (Polymorphism)
`Player` 추상 클래스를 상속받아 `Warrior`, `Magician`, `Archer`, `Thief` 클래스를 구현했습니다. `attack()` 함수를 순수 가상 함수로 선언하여 각 직업마다 고유한 공격 방식과 메시지를 출력하도록 설계했습니다.

### 2. 턴제 전투 로직 (Turn-based Battle)
플레이어와 몬스터가 서로의 공격력과 방어력을 계산하여 대미지를 주고받는 전투 루프를 구현했습니다. 몬스터 처치 시 랜덤 아이템 드롭 기능이 포함되어 있습니다.
- **최소 대미지 보장:** 방어력이 공격력보다 높더라도 최소 1의 대미지는 입히도록 설계

### 3. STL Vector 기반 인벤토리 & 제작소
`std::vector`를 사용하여 아이템 인벤토리를 관리하며, 포션 제작소(`AlchemyWorkshop`)에서는 이름이나 재료를 키워드로 레시피를 검색할 수 있는 기능을 제공합니다.

### 4. 입력 유효성 검사 (Input Validation)
사용자가 잘못된 값을 입력하거나 기준치 미만의 값을 입력할 경우, 올바른 값이 입력될 때까지 재입력을 유도하여 프로그램의 안정성을 높였습니다.

### 5. 추가 구현 사항 - 포션 제작
사용자가 포션 제작 레시피에 있는 아이템을 모두 소유한 상태에서 포션을 제작하길 희망할 시 포션이 제작될 수 있도록 포션 제작 기능을 추가하였습니다.

## 🛠️ 실행 방법 (Setup & Run)
비주얼 스튜디오에서 최종 결과물을 실행하려면 **시작 프로젝트 설정**이 필요합니다.

1. `project2.sln` 파일을 Visual Studio로 엽니다.
2. 우측 **솔루션 탐색기(Solution Explorer)**에서 **`project2`** 폴더(프로젝트)를 마우스 오른쪽 버튼으로 클릭합니다.
3. **[시작 프로젝트로 설정(Set as Startup Project)]**을 선택합니다.
4. 상단의 **로컬 Windows 디버거** 또는 `Ctrl + F5`를 눌러 프로그램을 실행합니다.
